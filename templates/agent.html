两个工具

工具输入返回耗时
news_sentiment
本地 SVM，不花 API 额度		 字符串数组，每条「标题。正文」 正面/中性/负面、−1..1 期望分、置信度 约 2 秒

工具只负责计算，结论仍由 agent 组织；两者都会把结果写进本地 SQLite（辩论进 debate_runs）， 所以这里能看到 agent 跑过什么。
